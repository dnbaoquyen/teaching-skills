# D09 – BẢNG THUẬT NGỮ ANH – VIỆT

**Học phần:** EVM1110E · **Phát:** Buổi 1, dùng suốt môn · **Nguồn:** 13 bảng thuật ngữ của tóm tắt LMS, chuẩn hóa theo D02 (bảng định nghĩa chuẩn).
**Quy ước:** giảng bằng tiếng Việt; thuật ngữ chuyên ngành giữ tiếng Anh, giải nghĩa tiếng Việt lần đầu. Trong bài viết, dùng **đúng một tên** cho mỗi khái niệm như bảng này.

## 1. Viết tắt dùng thường xuyên

| Viết tắt | Đầy đủ | Nghĩa trong môn |
|---|---|---|
| **KAM** | Key Account Management | Quản trị khách hàng trọng yếu |
| **KAP** | Key Account Plan | Kế hoạch cho một Key Account (bài giữa kỳ) |
| **SMP** | Stakeholder Management Plan | Kế hoạch quản trị các bên liên quan (bài cuối kỳ) |
| **DMU** | Decision-Making Unit | Nhóm người phía khách hàng cùng ra một quyết định mua |
| **CVP** | Customer Value Proposition | Đề xuất giá trị cho khách hàng |
| **CLV** | Customer Lifetime Value | Giá trị vòng đời khách hàng (5 năm, có chiết khấu) |
| **CTS** | Cost-to-serve | Chi phí agency bỏ ra **để phục vụ riêng** khách đó |
| **HSSEQ** | Health, Safety, Security, Environment, Quality | Sức khỏe, an toàn, an ninh, môi trường, chất lượng |
| **ROI** | Return on Investment | Lợi ích quy ra tiền so với chi phí đầy đủ |
| **KOL / KOC** | Key Opinion Leader / Key Opinion Consumer | Người dẫn dắt dư luận / người tiêu dùng có ảnh hưởng |
| **RFI / RFP / RFQ** | Request for Information / Proposal / Quotation | Yêu cầu thông tin / đề xuất / báo giá |
| **QBR** | Quarterly Business Review | Họp đánh giá chung định kỳ (theo quý) |
